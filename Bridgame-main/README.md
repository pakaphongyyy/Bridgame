# Bird Game — เกมนกเก็บหัวใจ

โปรเจกต์นี้เป็นเกมที่พัฒนาด้วยภาษา **Java** โดยใช้ **Java Swing** สำหรับสร้างหน้าจอและส่วนติดต่อผู้ใช้  
รูปแบบการเล่นเป็น **ผู้เล่นทีละ 1 คน** และระบบจะเก็บข้อมูลของผู้เล่นก่อนหน้าไว้เพื่อใช้แสดงประวัติและผลการเล่นภายหลัง

---

## แนวคิดของเกม

ผู้เล่นควบคุมนกให้บินผ่านท่อ เก็บหัวใจ และผ่านด่านต่าง ๆ โดยมีทั้งหมด 5 ด่าน

กติกาหลักของเกม

- เล่นได้ทีละ 1 คน
- ผู้เล่นกรอกชื่อก่อนเริ่มเกม
- หัวใจนับแยกในแต่ละด่าน
- เมื่อผ่านด่าน จำนวนหัวใจจะรีเซตเป็น 0
- จำนวนท่อที่ผ่านจะสะสมต่อเนื่องทุกด่าน
- เมื่อถึงด่าน 5 จะเป็นฉากจบ โดยให้นกบินเข้ารัง
- เมื่อจบเกม ระบบจะบันทึกผลของผู้เล่น
- ผู้เล่นคนถัดไปสามารถเล่นต่อได้ โดยข้อมูลของผู้เล่นก่อนหน้าจะยังคงอยู่

---

## เงื่อนไขการผ่านด่าน

| ด่าน | จำนวนหัวใจที่ต้องเก็บ |
|---|---:|
| ด่าน 1 | 10 |
| ด่าน 2 | 15 |
| ด่าน 3 | 20 |
| ด่าน 4 | 25 |
| ด่าน 5 | ฉากจบ — นกบินเข้ารัง |

ตัวอย่างการทำงาน

```text
ด่าน 1
เก็บหัวใจครบ 10 ดวง
        ↓
ผ่านด่าน
        ↓
หัวใจรีเซตเป็น 0
        ↓
เข้าสู่ด่าน 2
```

จำนวนท่อจะไม่รีเซต เช่น

```text
ด่าน 1 ผ่านท่อ 8 คู่
ด่าน 2 ผ่านเพิ่ม 6 คู่

จำนวนท่อสะสมทั้งหมด = 14 คู่
```

# การแบ่งความรับผิดชอบสำหรับสมาชิก 5 คน

เพื่อให้สมาชิกสามารถพัฒนาโปรเจกต์พร้อมกันได้โดยลดปัญหาการแก้ไฟล์ชนกัน จะแบ่งงานออกเป็น 5 ส่วนหลักดังนี้

---

## คนที่ 1 — ระบบหน้าจอและเมนูเกม

### รับผิดชอบ

ดูแลส่วนติดต่อผู้ใช้ หรือ **UI (User Interface)** ตั้งแต่หน้าเริ่มเกมจนถึงหน้าสรุปผล

### ไฟล์ที่รับผิดชอบหลัก

```text
StartFrame.java
PlayerSetupFrame.java
ResultFrame.java
AppFont.java
```

### งานที่ต้องทำ

- ออกแบบหน้า Start Menu
- สร้างช่องกรอกชื่อผู้เล่น
- สร้างปุ่มเริ่มเกม
- แสดงประวัติผู้เล่นก่อนหน้า
- สร้างหน้าสรุปผลหลังจบเกม
- สร้างปุ่มสำหรับผู้เล่นคนถัดไป
- ดูแลฟอนต์ภาษาไทย
- จัด Layout สี ปุ่ม และรูปแบบหน้าจอให้สวยงาม

### เป้าหมายของงาน

ผู้ใช้สามารถเปิดโปรแกรม กรอกชื่อ เริ่มเกม และดูผลหลังจบเกมได้อย่างสมบูรณ์

---

## คนที่ 2 — ระบบนกและการควบคุม

### รับผิดชอบ

ดูแลตัวละครนก การเคลื่อนไหว และระบบควบคุม

### ไฟล์ที่รับผิดชอบหลัก

```text
Bird.java
GamePanel.java
```

### งานที่ต้องทำ

- กำหนดตำแหน่ง X และ Y ของนก
- ทำระบบแรงโน้มถ่วง (Gravity)
- ทำระบบกระโดดหรือบินขึ้น
- รับคำสั่งจาก Keyboard
- กำหนดความเร็วในการตก
- วาดนกบนหน้าจอ
- เพิ่มภาพกราฟิกหรือ Animation ของนก
- ทำฉากนกบินเข้ารังในด่าน 5

### เป้าหมายของงาน

ผู้เล่นสามารถควบคุมนกให้บินขึ้นและตกลงได้อย่างเป็นธรรมชาติ

---

## คนที่ 3 — ระบบท่อ หัวใจ รัง และ Collision

### รับผิดชอบ

ดูแลวัตถุภายในเกม และตรวจสอบการชนทั้งหมด

### ไฟล์ที่รับผิดชอบหลัก

```text
Pipe.java
Heart.java
Nest.java
CollisionService.java
```

### งานที่ต้องทำ

- สร้างท่อจากด้านขวาของหน้าจอ
- เลื่อนท่อจากขวาไปซ้าย
- สุ่มตำแหน่งช่องว่างระหว่างท่อ
- สร้างหัวใจในตำแหน่งต่าง ๆ
- ตรวจการชนระหว่างนกกับท่อ
- ตรวจการชนพื้น
- ตรวจว่านกเก็บหัวใจหรือไม่
- ตรวจว่านกถึงรังหรือไม่
- กำหนด Hitbox ของนก ท่อ หัวใจ และรัง

### เป้าหมายของงาน

วัตถุในเกมเคลื่อนที่ได้ และระบบตรวจการชนหรือเก็บไอเทมได้ถูกต้อง

---

## คนที่ 4 — ระบบด่าน คะแนน และกติกาเกม

### รับผิดชอบ

ดูแล **Game Logic** หรือกติกาหลักทั้งหมดของเกม

### ไฟล์ที่รับผิดชอบหลัก

```text
GameEngine.java
GameState.java
LevelConfig.java
LevelService.java
ScoreService.java
Player.java
```

### งานที่ต้องทำ

- ควบคุม Game Loop
- เพิ่มจำนวนหัวใจเมื่อผู้เล่นเก็บได้
- เพิ่มจำนวนท่อเมื่อผู้เล่นบินผ่าน
- ตรวจสอบเงื่อนไขผ่านด่าน
- รีเซตหัวใจเมื่อเข้าสู่ด่านใหม่
- เก็บจำนวนท่อสะสมโดยไม่รีเซต
- เปลี่ยนความยากของแต่ละด่าน
- จัดการสถานะ Game Over
- จัดการด่าน 5 และฉากจบ
- เชื่อมข้อมูลระหว่าง Player, GameState และ GamePanel

### กติกาที่ต้องควบคุม

```text
ด่าน 1 = 10 หัวใจ
ด่าน 2 = 15 หัวใจ
ด่าน 3 = 20 หัวใจ
ด่าน 4 = 25 หัวใจ
ด่าน 5 = บินเข้ารัง
```

### เป้าหมายของงาน

ระบบสามารถนับคะแนน เปลี่ยนด่าน และตรวจเงื่อนไขจบเกมได้ถูกต้อง

---

## คนที่ 5 — ระบบบันทึกข้อมูล ทดสอบ และรวมระบบ

### รับผิดชอบ

ดูแลข้อมูลผู้เล่น การบันทึกประวัติ การรวมโค้ด และตรวจสอบความสมบูรณ์ของโปรเจกต์

### ไฟล์ที่รับผิดชอบหลัก

```text
FileStorageService.java
PlayerRecord.java
Main.java
GameFrame.java
```

### งานที่ต้องทำ

- บันทึกข้อมูลผู้เล่นลงไฟล์ CSV
- โหลดประวัติผู้เล่นเดิมกลับมาแสดง
- ตรวจว่าปิดโปรแกรมแล้วข้อมูลยังอยู่
- เชื่อม GameFrame กับระบบบันทึกข้อมูล
- ตรวจสอบการจบเกมและบันทึกผล
- รวมโค้ดจากสมาชิกทุกคน
- แก้ Error หลัง Merge
- ทดสอบโปรแกรมตั้งแต่เริ่มจนจบ
- ดูแล GitHub Repository และ Pull Request

### เป้าหมายของงาน

ข้อมูลผู้เล่นถูกบันทึกอย่างถูกต้อง และโค้ดจากทั้ง 5 ส่วนสามารถทำงานร่วมกันได้

# สรุปการแบ่งงาน

| สมาชิก | ส่วนที่รับผิดชอบ | งานหลัก |
|---|---|---|

| คนที่ 5 | Data / Integration | บันทึกข้อมูล รวมระบบ ทดสอบ และ GitHub |

# แนวทางการทำงานร่วมกันบน GitHub

แนะนำให้แต่ละคนสร้าง Branch แยกกัน

```text
main
│
├── feature/ui
├── feature/bird
├── feature/collision
├── feature/game-logic
└── feature/data
```

ตัวอย่างคำสั่ง

### คนที่ 1

```bash
git checkout -b feature/ui
```

### คนที่ 2

```bash
git checkout -b feature/bird
```

### คนที่ 3

```bash
git checkout -b feature/collision
```

### คนที่ 4

```bash
git checkout -b feature/game-logic
```

### คนที่ 5

```bash
git checkout -b feature/data
```

เมื่อทำงานเสร็จให้

```bash
git add .
git commit -m "อธิบายงานที่ทำ"
git push origin ชื่อ-branch
```

จากนั้นสร้าง **Pull Request** เพื่อรวมโค้ดเข้า `main`

> ไม่ควรให้สมาชิกทุกคนแก้โค้ดโดยตรงใน `main` พร้อมกัน เพราะจะทำให้เกิด Merge Conflict ได้ง่าย

# วิธีรันโปรแกรม

## โปรแกรมที่ต้องติดตั้ง

- Java JDK
- Visual Studio Code
- Extension Pack for Java

## ขั้นตอน

1. เปิด Visual Studio Code
2. เลือก `File > Open Folder`
3. เปิดโฟลเดอร์โปรเจกต์
4. เปิดไฟล์

```text
src/birdgame/Main.java
```

5. กด `Run` หรือกด `F5`
